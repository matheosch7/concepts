Build. Automate. Grow.

8-second style frame for the GemiVexa intro, animated in code, cut to a 120 BPM grid with synced hits, whooshes and UI sounds. Logo mark and colours are stand-ins until the brand kit arrives; the font is Poppins, as in the brief.

  1. 0.0–2.3 s · Build: a browser mockup assembles block by block on the beat, then a cursor clicks the CTA.
  2. 2.3–4.3 s · Automate: a lime diagonal wipe, then lead → AI agent → booked, with data packets running between nodes.
  3. 4.3–6.0 s · Grow: an iris transition opens from the check mark, bars rise on each beat and the trend arrow draws in.
  4. 6.0–8.0 s · End card: a panel wipe and impact, then the mark, wordmark, tagline words on half-beats, and the CTA.
